  1. 1
    กดปุ่ม คัดลอกกฎทั้งหมด ด้านล่าง
  2. 2
    เปิด Firebase Console → โปรเจกต์ english-pet-game → Realtime Database → แท็บ Rules
  3. 3
    ลบของเดิมทั้งหมด แล้ววางกฎที่คัดลอกมาแทน → กด Publish
    วางทั้งก้อนเสมอ ห้ามวางเฉพาะบางส่วน
