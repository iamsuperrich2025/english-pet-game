# GAME_RULES.md — กติกาเกมปัจจุบัน (state รุ่นใหม่)

> อ่านเมื่อ: แก้ระบบเกม (สัตว์/มื้ออาหาร/ความร้อน/บ้าน/บิล/แรงค์/โรงงาน/ตลาด/ออนไลน์/ชื่อ)

- `state.pets` = array (เลี้ยงหลายตัว ซื้อเพิ่มที่ร้านสัตว์ screen-select, จำกัดชนิดละ 1 ตัว), `state.active` = ตัวที่ดูแลอยู่, เลเวล/EXP/ชุด/ป่วย เก็บรายตัว, `state.owned` = ตู้เสื้อผ้ารวม
- **EXP โตช้าลง**: `expNeed(level)` = Lv.1→2 ต้อง 250 · Lv.2→3 ต้อง 600 · หลังจากนั้นเลเวลละ 400 (จับคู่ถูก +5 EXP, เมนูโปรด +15, สอบผ่านครั้งแรก +30)
- **มื้ออาหาร**: หิวทุก 3 ชม. (slot 0,3,6,...,21 น. — `currentSlotStart` ปัดลงขอบ 3 ชม., `SLOT_MS`) — `p.fedUpTo` = slot ล่าสุดที่กินครอบคลุม; หิวเกิน 2 ชม.ไม่กิน → ป่วย (`HUNGRY_SICK_MS`); feast อิ่ม 6 ชม. = ข้ามมื้อถัดไป; ราคาอาหาร 100–500, feast 1,000
- **ความร้อน**: ไม่มีบ้าน/บ้านไม่มีแอร์ → `p.heatFrom` นับสะสม ครบ 6 ชม.ป่วย (`HEAT_SICK_MS`) มีแถบร้อน; มังกร immune; ปลอดภัยเมื่อ `heatProtected()` = ปราสาท หรือบ้านกลาง+แอร์; ค่ารักษาป่วยทุกกรณี 1,000
- **ที่พัก**: เพิง 1,000 (กันฝนอย่างเดียว ติดแอร์ไม่ได้) · บ้านกลาง 100,000 (แอร์ 20,000+ติดตั้ง 5,000 = 25,000) · ปราสาท 1,000,000 (มีแอร์ในตัว); ย้ายบ้านแล้วแอร์ไม่ติดตามไป (`state.ac=false`)
- **ค่าบำรุงบ้าน**: 0.5% ของราคาบ้าน/เดือน (เพิง 5 · บ้าน 500 · ปราสาท 5,000) บิลออกทุกวันที่ 1 (`billTick` ใน careTick) เดือนแรกฟรี; ค้างจ่ายถึงวันที่ 5 → บ้านเสื่อม (`homeDecayed()` ภาพ `home_<id>_decayed.png`); ค้างข้ามเดือน → บ้านพัง (`state.pendingRuin` → ฉาก `showHomeRuined`) home=null; เซฟเก่ามีบ้าน → เริ่มบิลเดือนปัจจุบันฟรี
- **ค่าไฟ**: บิล id `elec` 0.5%/เดือน วันที่ 1 เดือนแรกฟรี; ค้างข้ามเดือน → **ถูกตัดไฟ** (`state.powerCut`, บิลค้างทบ) บ้านมืด (`home_<id>_dark.png`/ฟิลเตอร์) `heatProtected()` คืน false → สัตว์ร้อนป่วยทุก 6 ชม.แม้มีแอร์/ปราสาท (มังกร immune); จ่ายบิลค้างต้องซื้อ**หม้อแปลง 1,000** ก่อน (`state.transformerBought`, ผ่าน `payUtility('elec')`/`buyUtilityFix('elec')`) จ่ายครบ → ไฟกลับ เคลียร์ heatFrom; บ้านพัง(maint)→ล้างบิลสาธารณูปโภค+สถานะตัด; ซื้อ/ย้ายบ้าน→มิเตอร์ใหม่ฟรีเดือนแรก
- **ค่าน้ำ**: บิล id `water` 0.5%/เดือน (โครงเดียวกับค่าไฟ): ค้างสิ้นเดือน → **ตัดน้ำ** (`state.waterCut`) `home_<id>_nowater.png`; สัตว์**ทุกชนิดรวมมังกร** นับขาดน้ำ (`p.thirstFrom` แถบ `.thirst-fill`) ครบ 6 ชม. → ป่วย `cause:'thirst'` รักษา 1,000; ต้องจ่าย**ค่าติดตั้งระบบน้ำ 1,000** (`state.plumbingBought`) ก่อน; ภาพบ้านจัดลำดับ มืด(ไฟ) > แห้ง(น้ำ) > หม่น(ทรุด)
- **ค่าจัดการขยะ (ข้อ 13)**: บิล id `trash` 0.5%/เดือน วันที่ 1 เดือนแรกฟรี — **ไม่ตัด/ไม่พัง** ค้างข้ามเดือน→ปรับ +500 ทบใน `bills.trash.fine` (จ่ายครบ→รีเซ็ต 0); ไม่ผ่านเครื่อง UTILITIES (ไม่มี cutKey) ใช้ `trashBillUI()`/`payTrash()`
- **🏭 โรงงานผลิต & 🏪 ตลาด (แยกคนละแผง "รอบยี่สิบเก้า")**:
  - **โรงงาน (`#factory-card` = `renderFactoryCard`)**: เลือกสินค้าจากแคตตาล็อก 50 ชนิด (dropdown กรอง 5 หมวด `factoryCat` · แบ่งหน้า 5 รายการ/หน้า ปัดซ้ายขวา/ลูกศร `factoryPage`) กด "ผลิต" → `state.producing={id,progress}` · **ตอบคำศัพท์ถูก 1 คำ = 1 แต้มผลิต** (`addCraft` hook ใน checkMatch + finishQuiz) ครบแต้ม → เข้า `state.collection` + `producedCount++` + ฉาก `showCollectReveal(id,null,true)`
  - **ตลาด (`#market-card` = `renderMarketCard`)**: **📦 ออเดอร์พิเศษ** (`orderTick` ค้างสูงสุด 2 · เข้าใหม่ทุก 2–4 ชม. · หมดอายุ 24 ชม. · จ่าย 1.3–1.8× · ยังไม่เคยผลิต→ได้ common เท่านั้น) มีของในคลัง→ปุ่ม "ส่งมอบ" (`deliverOrder`) · **🎁 คลังของฉัน** (`renderCollectMine`): ตั้งราคาขาย `openListDialog`/`listingStatus` · `marketTick` ลูกค้าจำลองซื้อตามเวลา · กล่องขายสำเร็จ `tradeSold`
  - `assetValue` นับของในคลัง+ลงขายด้วยราคาฐาน (ของกำลังผลิตยังไม่นับ)
- **🎁 ส่งของขวัญ (ข้อ 0.5)**: ส่งของขวัญร้าน (gifts.js ซื้อด้วยเหรียญ) หรือ collectible จากคลังให้เพื่อน · escrow ตัดของ/หักเหรียญทันทีตอนส่ง · ผู้รับกดรับ→เข้า `state.giftBox` (ห้องของขวัญแยก) / ไม่รับ→คืนของ·เหรียญ · ค้าง 7 วัน→หมดอายุคืน · **ของใน giftBox ขายต่อ/ส่งต่อไม่ได้ ไม่รวม assetValue** (picker ดึงจาก `state.collection` เท่านั้น)
- **เหรียญ**: `addCoins()` อัปเดต `state.coins` + `state.daily.coins` (รีเซ็ตข้ามวัน `dailyTick()`) — dashboard 2 pill
- **แรงค์**: ยึด **net worth = เหรียญ + assetValue** (ทรัพย์สินคิดราคาเต็มที่ซื้อ รวมมือถือ/คอม; ราคาขายคืนใช้ตอนขายจริง → ซื้อแล้วแรงค์ไม่ตก); 7 แรงค์ (บรอนซ์ 0/ซิลเวอร์ 10k/โกลด์ 200k/แพลตินัม 1M/ไดมอนด์ 2M/มาสเตอร์ 4M/จอมพล 20M) ขั้นย่อย III→II→I; ตรวจที่ `refreshRank()` ใน careTick (เทียบ `state.rankKey`) ข้ามแรงค์ใหญ่→`showRankUp()` · ขั้นย่อย→toast · ลด→เงียบ
- **นาฬิกา**: `#clock-chip` โชว์ วัน·วันที่·เวลา (th-TH) เดินทุกวินาที (`renderClock`)
- **การ์ดเพื่อนออนไลน์** `#online-card`: ต่อ Firebase→ผู้เล่นจริง (`Online.friends` จาก `/presence`, onDisconnect ลบเอง, ผีค้าง 10 นาทีกรอง) / ออฟไลน์→เพื่อนจำลอง · **🏆 Leaderboard** `#leaderboard-card` Top 50 อันดับ**เหรียญคงเหลือ** (`state.coins`) จาก `/leaderboard` สด · แถวตัวเองไฮไลต์เหลือง+⭐ · คลิกชื่อ→การ์ดโชว์เงิน/จำนวนทรัพย์สิน/มูลค่าทรัพย์สิน (av/ni)
- **คำศัพท์ตามชั้น**: register ป.1–ม.6 → `gradeBand()` เลือก band; ใช้ `catsForStudent()`/`vocabForStudent()`
- เล่นเกม/สอบได้แม้ยังไม่มีสัตว์ (ได้เหรียญ+RP ไม่ได้ EXP) — เริ่มเกมเก็บ 3,000 ก่อนซื้อหมา/แมว
- **🔐 Google Login (ข้อ 0.1)**: เข้าเกมต้อง login (แบบ ก. บังคับ) `#screen-login` · เซฟจริง `/users/<uid>/save={data:JSON, at}` — localStorage เป็น cache เทียบ `state.savedAt` vs `cloud.at` · `state.ownerUid`=เจ้าของ (null=ยุคก่อน login ถามผูก 2 ชั้น · บัญชีอื่น=เริ่มใหม่เงียบ) · push ทุก 1 นาที+beforeunload+จุดสำคัญ · logout=push→signOut→ล้าง cache→reload · **ปุ่มรีเซ็ตถูกถอด** (รีเซ็ตทาง console เท่านั้น) · login จริงเฉพาะ http/https · presence/leaderboard ใช้ **uid** เป็น key (`onlineKey()`)
- **📛 ชื่อในเกม (ข้อ 0.2)**: `state.profileName` ตั้งตอนลงทะเบียน (`#reg-nick`) · ผู้เล่นเดิมไม่มีชื่อ→กล่องบังคับ `authAskProfileName()` (ปิดข้ามไม่ได้) · ตรวจ `checkName(raw,2,20)` · เก็บสำเนาสาธารณะ `/users/<uid>/profile/name` (`authPushProfile()`) · `onlineDisplayName()` ใช้ profileName ก่อน · ชื่อจาก DB ทุกจุด `escapeHTML()` ก่อนแทรก innerHTML
- **📛 ชื่อสัตว์ (ข้อ 7)**: `p.name` บังคับตั้งตอนซื้อ (ยกเลิก=ไม่ซื้อ) · ปุ่ม ✏️ เปลี่ยนภายหลัง · `checkName(raw,1,15)` · migration ตัวเดิม=ชื่อชนิด
- **ล็อกร้านค้า**: ไม่มีสัตว์ หรือ active เป็นไข่/แรกเกิด (Lv.1) → ร้านไอเทม lock-banner
