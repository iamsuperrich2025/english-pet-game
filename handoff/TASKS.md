### ✅ รอบ 234 (14 ก.ค.) — 🚗 GPS แม่นขึ้น: ตัดจุดเลี้ยวผีบนถนนเฉียง (string-pulling) (version .224 · SW v19)
ผู้ใช้ส่ง screenshot: GPS สั่ง "เลี้ยวขวา" ตอนนี้ · เลี้ยวจริง = **ตกถนน** · ขอปรับ GPS ให้แม่นกว่านี้
- **ต้นตอ (ยืนยัน unit test):** กริดถนน `GS=6ม.` · A* เดินแบบ**ขั้นบันได**บนถนนที่วางเฉียง · การย่อจุดเดิม (collinear) เก็บทุกมุมกริด → **จุดเลี้ยวผีทุก 6ม.** (ซ้าย-ขวาสลับ) ทั้งที่ถนนตรง · GPS อ่านขั้นบันไดเป็น "เลี้ยวขวา" ผู้เล่นหักเลี้ยวจริง = ออกนอกถนน
- **แก้ (adventure3d.js):** (1) **`losClear(D,ax,az,bx,bz)`** — line-of-sight บนถนน (สุ่มจุดตามเส้นตรงทุก GS/2 เช็ก `cellDrivable`) (2) **`routeGrid` string-pulling** — หลัง collinear แล้ว รวมช่วงที่มองเห็นตรงๆบนถนนเป็นเส้นเดียว (greedy จากปลายไกลสุดที่ LOS ผ่าน) → เหลือเฉพาะ**มุมเลี้ยวจริงที่แยกถนน** (3) **`tickGps` precompute turn ข้ามช่วงสั้น (<9ม.)** — ทิศช่วงสั้น=noise (โดยเฉพาะช่วงสุดท้ายไปตัวอักษร) กันเลี้ยวผีตอนใกล้ถึง (4) โชว์ระยะถึง**จุดเลี้ยว** (ไม่ใช่ระยะถึงตัวอักษร) เมื่อ turnDist<70ม. + ป้าย **"เลี้ยว…เลย"** ตอน <16ม. (เดิมโชว์ "เลี้ยวขวา"+ระยะถึงตัวอักษร 478ม. = สับสน)
- **ยืนยัน (unit test กริดสังเคราะห์ในเบราว์เซอร์ · คัดลอกฟังก์ชันจริง):** ถนนเฉียง slope0.5 → **OLD 55จุด/54เลี้ยวผี → NEW 2จุด/0เลี้ยว** · ถนนหักฉาก L = เลี้ยว 1 ครั้งเป๊ะ (มุมจริงคงไว้) · ถนนตรงแนวแกน 0 เลี้ยว · `losClear` ปลาย→ปลาย L = false (ไม่ลัดตัดมุมนอกถนน) · การ์ด <9ม. → destination noise หาย · syntax parse ผ่าน · deploy live .224 (curl ยืนยัน losClear ขึ้นเว็บ)
- ⚠️ **ค้าง: ผู้ใช้ลองจริงมือถือ** — ขับตามเส้นทางเฉียง ดูว่า GPS ไม่สั่งเลี้ยวมั่วแล้ว + ป้าย "เลี้ยว…เลย" ตรงจังหวะแยกจริง
