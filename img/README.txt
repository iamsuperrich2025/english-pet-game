วางภาพสัตว์เลี้ยง (.png พื้นหลังโปร่งใส) ในโฟลเดอร์นี้
ดูรายชื่อไฟล์และ prompt เจนภาพครบชุดได้ที่ PROMPTS.md (โฟลเดอร์แม่)

ระวัง! อย่าให้ชื่อไฟล์นามสกุลซ้อนเป็น .png.png
(เปิด File Explorer > View > Show > File name extensions ไว้จะเห็นชื่อจริง)

ตัวอย่างชื่อไฟล์:
  dog_newborn.png          ลูกหมาแรกเกิดหลับตาในตะกร้า (หมาเกิดเป็นตัว ไม่ฟักจากไข่)
  cat_newborn.png          ลูกแมวแรกเกิดหลับตาในตะกร้า
  dragon_egg.png           ไข่มังกร (สัตว์ในนิทานฟักจากไข่ได้)
  cat_baby_hungry.png      แมวร่างเด็ก กำลังหิว
  dragon_adult_crown.png   มังกรโตเต็มวัย ใส่มงกุฎ

สัตว์:  dog, cat, dragon
วัย:    baby, adult
อาการ:  normal, happy, hungry, sick
ไอเทม:  bow, cap, bell, glasses, scarf, tophat, sunglasses, crown

วางไฟล์แล้วรีเฟรชเกม ระบบจะดึงภาพไปแสดงเองอัตโนมัติ
ภาพไหนยังไม่มี เกมจะใช้อีโมจิแทนชั่วคราว
(dog_egg.png เดิมไม่ถูกใช้แล้ว ลบทิ้งได้)
