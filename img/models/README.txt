โฟลเดอร์นี้ใส่ไฟล์โมเดล 3D (.glb) ของตัวละครหน้า Lobby
=========================================================

เกมจะโหลดไฟล์เหล่านี้เอง ถ้ามีครบ = โชว์ 3D (idle + ปัดหมุน 360°)
ถ้าไม่มี / ไม่ครบ = ใช้ภาพ PNG เดิม (ไม่พัง)

ชื่อไฟล์ต้องตรงเป๊ะ (ตัวพิมพ์เล็ก .glb):
  ผู้เลี้ยง:  caretaker_male.glb   caretaker_female.glb
  น้องสัตว์:  pet_dog.glb   pet_cat.glb   pet_dragon.glb

ต้องมีครบ "ผู้เลี้ยง + น้องของชนิดนั้น" ถึงจะขึ้น 3D
(เช่น เลี้ยงหมา+เป็นเด็กชาย → ต้องมี caretaker_male.glb และ pet_dog.glb)

วิธีเจนโมเดลจากภาพตัวละครเดิม + สเปกไฟล์: ดู PROMPTS_MODELS_3D.md
